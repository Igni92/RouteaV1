# Mapbox Token Setup (optional, can use free tier)

1. Va sur https://mapbox.com
2. Sign up (gratuit)
3. Va dans "Account" → "Tokens"
4. Copie le token par défaut (commence par "pk.eyJ")
5. Mets-le dans /frontend-manager/.env → VITE_MAPBOX_TOKEN
